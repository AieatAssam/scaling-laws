# Play Store pack: Scaling Laws

Everything needed to fill in the Google Play Console listing for `net.aieat.scalinglaws`.
Run `store/listing/check.sh` to verify text limits, ASCII text, image sizes and that no image has an alpha channel.

## Files

| File | Use |
| --- | --- |
| `listing/en-GB/title.txt` | App name (30 characters max) |
| `listing/en-GB/short_description.txt` | Short description (80 max) |
| `listing/en-GB/full_description.txt` | Full description (4000 max) |
| `listing/en-GB/release_notes.txt` | Release notes for the first release (500 max) |
| `graphics/icon-512.png` | High-resolution app icon (512x512, RGB, no alpha) |
| `graphics/feature-graphic-1024x500.png` | Feature graphic (1024x500, RGB, no alpha) |
| `screenshots/phone/*.png` | Phone screenshots: six frames, 1080x1920 |
| `screenshots/tablet7/*.png` | 7-inch tablet screenshots: two frames, 1920x1080 |
| `screenshots/tablet10/*.png` | 10-inch tablet screenshots: two frames, 1920x1080 |
| `privacy-policy.md` | Privacy policy text (same text as the published page) |
| `../docs/privacy.html` | Published privacy policy page |
| `../video/out/scaling-laws-promo.mp4` | Promo video, for the YouTube link |

The graphics and screenshots are regenerated by `tools/dev_store_graphics.gd` and `tools/dev_store_shots.gd`.

## Play Console checklist

### Create the app
- [ ] Create app, default language English (United Kingdom), app name from `title.txt`.
- [ ] App or game: Game. Free or paid: set to match how the app is offered. The app has no ads and no in-app purchases.
- [ ] Declarations: confirm the developer policy and US export law declarations.

### Store listing
- [ ] App name: paste `listing/en-GB/title.txt`.
- [ ] Short description: paste `listing/en-GB/short_description.txt`.
- [ ] Full description: paste `listing/en-GB/full_description.txt`.
- [ ] App icon: upload `graphics/icon-512.png`.
- [ ] Feature graphic: upload `graphics/feature-graphic-1024x500.png`.
- [ ] Phone screenshots: upload the six files in `screenshots/phone/`, in numbered order.
- [ ] 7-inch tablet screenshots: upload the two files in `screenshots/tablet7/`.
- [ ] 10-inch tablet screenshots: upload the two files in `screenshots/tablet10/`.
- [ ] Promo video: paste the YouTube link for the promo video. Upload `video/out/scaling-laws-promo.mp4` to YouTube first. Do not modify anything in `store/video/`.
- [ ] Category: Games > Simulation.
- [ ] Tags and contact details: fill in the developer email shown in the console (it is not stored in this repo).

### Privacy and policy
- [ ] Privacy policy URL: `https://aieatassam.github.io/scaling-laws/privacy.html`
- [ ] Data safety form: the app collects no data and shares no data. No data is encrypted in transit because the app sends nothing. Saves stay on the device.
- [ ] Ads: the app contains no ads, so answer "No" to "Does your app contain ads?"
- [ ] App access: the app needs no login or account, so answer that no special access is required.
- [ ] Content rating: complete the IARC questionnaire. The app has no violence, no sexual content, no user-generated content, no location sharing and no purchases, so expect the lowest rating.
- [ ] Target audience: 13 and over. Do not select the children's designed-for-families programme.
- [ ] News app and COVID-19 declarations: answer No.
- [ ] Government app: answer No.

### Release
- [ ] Upload the first Android App Bundle (`.aab`) from the GitHub release. Do not build it locally for upload.
- [ ] Enrol in Play App Signing when the console asks. Keep the upload key backed up.
- [ ] Paste `listing/en-GB/release_notes.txt` into the release notes.
- [ ] Set the production track or a test track, then send for review.

## Not in this repo

- Developer account, payment profile and identity verification.
- Developer contact email shown on the listing.
- The YouTube upload itself and its visibility setting.
- Final review and rollout decisions.
